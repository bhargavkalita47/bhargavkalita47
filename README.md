## Featured work

### [CivicWatch](https://github.com/bhargavkalita47/civicwatch) · [Live app](https://civicwatch.bhargavkalita1327.workers.dev/)

A map-based community platform for reporting and discussing neighbourhood infrastructure issues. Residents can place reports, upload photo evidence, follow discussions, and track resolution.

- Built responsive map exploration, location search, report workflows, community threads, and moderation interfaces.
- Extended the app beyond its frontend prototype with a Cloudflare Worker API, Supabase-backed accounts and data, role-aware operations, and paginated report views.
- **Stack:** React, TypeScript, Leaflet, OpenStreetMap, Cloudflare Workers, Supabase, PostgreSQL.

### [Shikshak](https://github.com/Bhargav-shikshak/shikshak) · [Website](https://shikshak.co.in/)

A neighbourhood-focused tutoring platform where students discover teachers and request classes. Teachers accept or decline bookings, and accepted classes unlock communication and learning tools.

- Implemented map/list discovery, booking flows, teacher and student workspaces, chat, lesson notes, and PDF homework.
- Connected the application to Supabase through a Cloudflare Worker, with role-based access and private classroom resources.
- Continuing work on teacher-controlled rates, distance-based pricing, verification, and owner/admin controls.
- **Stack:** React, TypeScript, Leaflet, Cloudflare Workers, Supabase.

### [Atlas](https://github.com/bhargavkalita47/Atlas)

An open-source, reusable mapping toolkit and visual development playground, created to make maps more configurable without tying every application to a paid map API.

- Supports Leaflet raster maps and MapLibre vector maps, along with markers, geocoding, shapes, and map styling.
- Developing adjustable map presets, layer visibility/opacity controls, and a workflow for eventually integrating custom styles into other apps.
- Improved loading and interaction through renderer splitting, selective preloading, caching, resolution scaling, and mobile gesture stabilization. Measured an approximately **82% reduction in initial uncompressed application JavaScript** after renderer splitting (not total vector-map load time).
- **Stack:** TypeScript, React, MapLibre GL JS, Leaflet, Vite, OpenStreetMap.

### [Dockline](https://github.com/bhargavkalita47/dockline)

An industrial warehouse management application covering multi-warehouse stock, shelving, receiving, order fulfilment, and inter-warehouse transfers. Its current interactive implementation uses browser-local persistence, with service and domain boundaries designed for a future shared backend.

**Stack:** React, TypeScript, domain-driven workflow logic.

### [Recruider](https://github.com/bhargavkalita47/Recruider-MVP)

A skill-first hiring platform built around candidate work, challenges, recruiter discovery, mutual interest, and messaging.

**Stack:** React, TypeScript, Supabase Auth, PostgreSQL, Realtime.

**Other work:** [Pantry](https://github.com/bhargavkalita47/Pantry) (menu-linked inventory) · [TradeLedger](https://github.com/bhargavkalita47/trading-journal) (trading journal and simulated portfolio tracking).
